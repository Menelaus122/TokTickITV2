## Agent skills

### Issue tracker

Issues live in GitHub Issues for `Menelaus122/TokTickITV2`, managed with the `gh` CLI. Their status lives on the **TokTickIT Individual Sprints** Project board, and PRs target the current lab's `labN-staging`. See `docs/agents/issue-tracker.md`.

PR titles and bodies follow the format in `docs/agents/issue-tracker.md`, not the `pr` skill's template.

### Triage labels

No triage labels: each triage role maps to a board column (`ready-for-agent` → Specified). See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `CONTEXT.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
